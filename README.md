# bonoboengine.wasm.3D
3D Wasm Web Assembly C# browser-wasm monorepo: a pure C# game engine, a Roslyn analyzer + source generator project, a shared class library owning the BabylonJS frontend, a non-Blazor browser-wasm host, an example catalog, and a TypeScript-driven BabylonS build managed by Vite and Tailwind.
